Bangk-Shield berjalan sepenuhnya di Cloudflare Workers. Setiap request yang mencurigakan
diintersep sebelum menyentuh origin, lalu dibalas dengan response palsu yang masuk akal —
lengkap dengan roast bernuansa lokal, watermark kriptografis, dan log serangan yang persisten.

## Mulai dari mana?

- **Baru pertama kali?** Baca [Pendahuluan](/mulai/pendahuluan/) lalu ikuti [Instalasi](/mulai/instalasi/).
- **Ingin langsung mencoba?** [Mulai Cepat](/mulai/mulai-cepat/) memandu `npm run dev` dan beberapa `curl` uji serangan.
- **Ingin tahu cara kerjanya?** [Arsitektur & Alur Request](/konsep/arsitektur/) menjelaskan urutan evaluasi dari awal sampai response.
- **Mengubah aturan deteksi?** Mulai dari [Rule Engine](/konsep/rule-engine/) dan [Referensi rules.json](/konfigurasi/rules/).

:::caution[Status Beta]
Versi ini adalah rewrite arsitektur, bukan iterasi kecil. Rule engine dipindah ke build pipeline
terkompilasi, ditambah circuit breaker, watermark kriptografis, dan logging dengan sampling.
Beberapa fitur PRD — admin dashboard dan circuit breaker level 2 — belum diimplementasikan.
Lihat [Batas Kemampuan](/referensi/batas-kemampuan/) sebelum memakai di produksi.
:::
